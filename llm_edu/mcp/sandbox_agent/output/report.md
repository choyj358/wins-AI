# CVE 점검 보고서

## 자산 목록
- Apache Log4j / 2.14.1 / 플랫폼팀
- Cisco AnyConnect / 4.9.0 / 인프라팀

## 확인 방법
1. `input/assets.md`에서 사용 중인 제품과 버전을 확인함.
2. 각 제품 관련 CVE를 `cve-lookup`으로 조회함.
3. 조회된 취약 버전 범위와 사내 사용 버전을 비교해 영향 여부를 판정함.

## 점검 결과

### 1) Apache Log4j 2.14.1
- 조회 CVE: `CVE-2021-44228`
- 조회 결과: 영향 버전 `2.0-beta9 ~ 2.14.1`, 조치 버전 `2.17.1`
- 판정: **영향 받음**
- 사유: 사용 버전 `2.14.1`이 영향 범위에 포함됨.

### 2) Cisco AnyConnect 4.9.0
- 관련 CVE를 조회했으나 사내 DB에서 등록 항목을 확인하지 못함.
- 판정: **DB 기준 확인 불가**
- 비고: 추가로 벤더 공지/패치 노트를 확인해야 함.

## 요약
- 영향 확인됨: Apache Log4j 2.14.1
- 확인 불가: Cisco AnyConnect 4.9.0
